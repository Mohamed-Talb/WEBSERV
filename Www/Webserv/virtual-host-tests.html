03 — VIRTUAL HOSTS

SERVER BLOCK TESTS

Run these commands in another terminal while Webserv is running. They test virtual-host selection and multiple listening ports.

Browser JavaScript cannot manually set the Host header, so curl is required for alpha.local and beta.local.

ALPHA VIRTUAL HOST

curl -i -H "Host: alpha.local" http://127.0.0.1:8080/

Expected body: ALPHA VIRTUAL HOST

BETA VIRTUAL HOST

curl -i -H "Host: beta.local" http://127.0.0.1:8080/

Expected body: BETA VIRTUAL HOST

UNKNOWN HOST

curl -i -H "Host: unknown.local" http://127.0.0.1:8080/

Expected: the first server block configured for 127.0.0.1:8080.

HOST NAME WITH PORT

curl -i -H "Host: alpha.local:8080" http://127.0.0.1:8080/

Expected body: ALPHA VIRTUAL HOST

CASE-INSENSITIVE HOST

curl -i -H "Host: ALPHA.LOCAL" http://127.0.0.1:8080/

Expected body: ALPHA VIRTUAL HOST

SECOND LISTENING PORT

curl -i http://127.0.0.1:9090/

Expected body: SERVER ON PORT 9090

HTTP/1.1 WITHOUT HOST

printf 'GET / HTTP/1.1\r\nConnection: close\r\n\r\n' | nc 127.0.0.1 8080

Expected status: 400 Bad Request

HTTP/1.0 WITHOUT HOST

printf 'GET / HTTP/1.0\r\nConnection: close\r\n\r\n' | nc 127.0.0.1 8080

Expected: the default server response.
