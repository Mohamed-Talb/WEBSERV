C++98 HTTP SERVER

WEBSERV

A non-blocking HTTP server that manages clients, parses requests, serves resources, and executes CGI scripts.

ARCHITECTURE

PROJECT STRUCTURE

MAIN PARTS

01

SERVER

  • Accepts client connections
  • Uses non-blocking sockets
  • Manages events with epoll()
  • Controls connections and timeouts
02

CONFIGURATION

  • Reads server and location blocks
  • Defines hosts and ports
  • Defines routes and methods
  • Configures CGI, uploads, and errors
03

HTTP

  • Parses requests
  • Supports GET, POST, and DELETE
  • Matches routes and resources
  • Creates HTTP responses
04

CGI

  • Executes dynamic scripts
  • Creates child processes
  • Uses input and output pipes
  • Converts CGI output into a response
