06 — SESSION

COOKIES & SESSIONS

Create a server-side session, store its identifier in an HttpOnly cookie, update its variables, and inspect all sessions stored in the JSON file.

The browser stores only the session ID. The CGI script stores the session variables and expiration std::time inside a JSON file.
