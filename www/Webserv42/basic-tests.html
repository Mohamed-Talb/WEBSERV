02 — BASIC TESTS

HTTP BEHAVIOUR CHECKS

Run safe browser-side checks for routing, methods, redirects, CGI failures, and path normalization.

The CGI timeout check uses an intentionally slow or infinite script and may take the configured server timeout duration. A browser cannot send malformed raw HTTP requests, so use the project tester or Netcat for those checks.
