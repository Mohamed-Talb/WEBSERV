CONFIGURATION REFERENCE

CONFIGURATION RULES

This page describes the configuration syntax accepted by Webserv. Every directive must end with a semicolon, and every server or location block must be enclosed in braces.

SERVER DIRECTIVES

LISTEN

Defines the host and port on which the server accepts connections. A port without a host uses 0.0.0.0. A host without a port uses port 80.

SYNTAX: listen host:port;

VALID

listen 8080;
    listen 127.0.0.1:8080;
    listen localhost:8080;
    listen localhost;

INVALID

listen;
    listen 127.0.0.1:;
    listen :8080;
    listen 99999;
    listen localhost:8080:9000;

SERVER_NAME

Defines one or more names accepted by the virtual server.

SYNTAX: server_name name ...;

VALID

server_name localhost;
    server_name example.com www.example.com;

INVALID

server_name;

ROOT

Defines the default filesystem directory used to resolve requested files. Trailing slashes are removed and repeated slashes are collapsed.

SYNTAX: root path;

VALID

root ./www/Webserv42;
    root ./www/Webserv42/;

INVALID

root;
    root ../www;
    root ./www/../private;

INDEX

Defines one or more files checked when the requested resource is a directory. Leading slashes are removed from index filenames.

SYNTAX: index filename ...;

VALID

index index.html;
    index index.html index.htm;
    index /index.html;

INVALID

index;
    index ../index.html;
    index /;

CLIENT_MAX_BODY_SIZE

Defines the maximum accepted request-body size. The value must be a positive whole number with an optional supported unit.

SYNTAX: client_max_body_size size;

VALID

client_max_body_size 10000000;
    client_max_body_size 512K;
    client_max_body_size 10MB;
    client_max_body_size 1G;

INVALID

client_max_body_size 0;
    client_max_body_size -1;
    client_max_body_size 1.5M;
    client_max_body_size 20T;

ERROR_PAGE

Associates one or more supported HTTP error codes with an internal error-page URI. The same status code cannot be configured more than once.

SYNTAX: error_page code ... path;

VALID

error_page 404 /errors/404.html;
    error_page 400 403 /errors/client-error.html;
    error_page 500 501 504 /errors/server-error.html;

INVALID

error_page;
    error_page 404;
    error_page abc /errors/error.html;
    error_page 404 ../errors/404.html;

LOCATION

Creates a configuration block for a URL prefix. Location paths must start with /, cannot contain .., and must be unique inside the same server.

SYNTAX: location path { ... }

VALID

location /upload
    {
        methods GET POST DELETE;
        root ./www/Webserv42;
    }

INVALID

location upload
    {
        methods GET;
    }

    location /../private
    {
        methods GET;
    }

LOCATION DIRECTIVES

METHODS

Defines the HTTP methods allowed for the location. Each method may appear only once.

SYNTAX: methods method ...;

VALID

methods GET;
    methods GET POST;
    methods GET POST DELETE;

INVALID

methods;
    methods GET GET;
    methods CONNECT;
    methods RANDOM;

ROOT

Overrides the server root for the location. When omitted, the location inherits the server root.

SYNTAX: root path;

VALID

root ./www/Webserv42;
    root ./www/Webserv42/cgi_bin;

INVALID

root;
    root ../private;

INDEX

Overrides the server index list for this location. When omitted, the location inherits the server index files.

SYNTAX: index filename ...;

VALID

index index.html;
    index index.html index.py;

INVALID

index;
    index ../index.html;

AUTOINDEX

Enables or disables generated directory listings. Only the exact values on and off are accepted.

SYNTAX: autoindex on|off;

VALID

autoindex on;
    autoindex off;

INVALID

autoindex;
    autoindex yes;
    autoindex true;

CGI_EXT

Defines the extension handled as CGI. A leading dot is added when it is missing. This directive requires cgi_path.

SYNTAX: cgi_ext extension;

VALID

cgi_ext .py;
    cgi_ext py;

INVALID

cgi_ext;
    cgi_ext .;
    cgi_ext ../py;
    cgi_ext /py;

CGI_PATH

Defines the executable used to run CGI scripts. This should point to an interpreter such as /usr/bin/python3. It requires cgi_ext.

SYNTAX: cgi_path executable;

VALID

cgi_path /usr/bin/python3;
    cgi_path /usr/bin/php-cgi;

INVALID

cgi_path;
    cgi_path ../python3;

UPLOAD

Enables or disables file uploading. When uploads are enabled, upload_path is required.

SYNTAX: upload on|off;

VALID

upload on;
    upload off;

INVALID

upload;
    upload yes;
    upload true;

UPLOAD_PATH

Defines the directory where uploaded files are stored. It is required when upload on is configured and rejected when uploads are disabled.

SYNTAX: upload_path path;

VALID

upload on;
    upload_path upload;

INVALID

upload on;
    # upload_path is missing

    upload off;
    upload_path upload;

RETURN

Redirects matching requests to another internal URI or external URL. Only status codes 301 and 302 are accepted.

SYNTAX: return code target;

VALID

return 301 /new-path;
    return 302 https://example.com;

INVALID

return;
    return 307 /new-path;
    return 301 new-path;
    return 301 ../private;

CLIENT_MAX_BODY_SIZE

Overrides the server request-body limit for this location. When omitted, the location inherits the server value.

SYNTAX: client_max_body_size size;

VALID

client_max_body_size 10M;
    client_max_body_size 512KB;

INVALID

client_max_body_size 0;
    client_max_body_size 2.5M;
    client_max_body_size 5T;
