01 — ABOUT

THE PROJECT

A FULLY FUNCTIONAL HTTP/1.1 SERVER BUILT FROM SCRATCH IN C++98

This project implements a complete web server following the HTTP/1.1 protocol specification. It handles multiple simultaneous connections, serves static files, and executes CGI scripts for dynamic content generation.

IMPLEMENTATION DETAILS

01

SOCKET MANAGEMENT

One listening socket is created for each configured port, with all sockets multiplexed through a single poll() loop. Every accepted connection has its own read and write buffers, so a slow client never blocks the others.

02

REQUEST PARSING

Requests are parsed incrementally as bytes arrive: request line, headers, and body. The parser handles Content-Length and chunked transfer encoding before passing a complete request to the handler.

03

CGI PIPELINE

When a request matches a CGI route, the server forks a child process, creates the standard CGI environment variables, sends the request body through standard input, and reads the generated response through standard output.
