About

The Project

A fully functional HTTP/1.1 server built from scratch in C++98

This project implements a complete web server following the HTTP/1.1 protocol specification. It handles multiple simultaneous connections, serves static files, and executes CGI scripts for dynamic content generation.

Server Architecture

Technical Specifications

A

Architecture

  • C++98 standard compliant
  • Non-blocking I/O with poll()
  • Multi-port listening
  • Configurable via .conf file
B

HTTP methods

  • GET — resource retrieval
  • POST — data submission
  • DELETE — resource removal
  • Full header parsing
C

CGI support

  • PHP script execution
  • Python script execution
  • Fork/execve implementation
  • Environment variable passing
D

File handling

  • Static file serving
  • Multipart file upload
  • MIME type detection
  • Directory indexing

Implementation Details

01

Socket management

One listening socket per configured port, all multiplexed through a single poll() loop. Each accepted connection is tracked with its own read/write buffers so a slow client on one socket never blocks the others.

02

Request parsing

Requests are parsed incrementally as bytes arrive: request line, headers, then body — respecting Content-Length and chunked transfer encoding before the handler ever sees a complete request.

03

CGI pipeline

On a CGI-mapped route, the server forks, sets up the standard CGI environment variables, pipes the request body to stdin, and streams stdout back to the client as the response body.
